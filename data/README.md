# Data Documentation

## Overview

This folder contains instructions for obtaining and preparing the data used 
in this analysis. **No data files are included in this repository** to keep 
size manageable.

## Public Data Sources

All data required is **open and publicly available**:

### 1. IBGE Census 2022 – Census Sectors (Setores Censitários)

Os dados utilizados nesta monografia são provenientes da malha de setores censitários e do arquivo de agregados por setores censitários3, ambos extraídos do Censo Demográfico de 2022. Esses instrumentos são disponibilizados pelo IBGE e atualizados a cada edição do Censo Demográfico, estando acessíveis publicamente para todo o território
nacional. 

- A malha de setores censitários está disponível no endereço <https://www.ibge.gov.br/geociencias/
downloads-geociencias.html?caminho=organizacao_do_territorio/malhas_territoriais/malhas_de_
setores_censitarios__divisoes_intramunicipais/censo_2022/setores/gpkg/UF>(Acesso em: 22 de
maio de 2025)

- Os arquivos de Agregados por setores censitários estão disponíveis em <https://www.ibge.gov.br/
estatisticas/downloads-estatisticas.html?caminho=Censos/Censo_Demografico_022/Agregados_
por_Setores_Censitarios/Agregados_por_Setor_csv/> (Acesso em: 22 de maio de 2025)
